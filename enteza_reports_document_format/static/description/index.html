Enteza Reports Document Format

Módulo para Odoo 19 que proporciona formatos de documentos personalizados con agrupación por categorías de producto.

Características Principales

📋 Pedidos de Venta

  • Reporte agrupado por categorías de producto
  • Visualización de precio de coste
  • Campo para fecha de evento
  • Información detallada del cliente y direcciones

📦 Albaranes de Entrega

  • Reporte agrupado por categorías de producto
  • Información de cliente y fecha del evento
  • Cantidades pedidas vs entregadas
  • Soporte para pedidos pendientes (backorders)

💰 Facturas

  • Reporte agrupado por categorías de producto
  • Campo adicional para fecha de evento
  • Agrupación por secciones de líneas
  • Vista mejorada de totales de impuestos

Instalación

  1. Actualizar la lista de módulos
  2. Buscar "Enteza Reports Document Format"
  3. Hacer clic en "Instalar"

Uso

Una vez instalado, los nuevos reportes están disponibles en el menú de impresión de cada documento:

  • Pedidos de venta: "Pedido/Presupuesto Agrupado"
  • Albaranes: "Albarán Agrupado"
  • Facturas: "Factura Agrupada"
